# AI Resume Analyzer 🚀

An AI-powered web app that analyzes resumes, suggests best roles, calculates ATS score, and provides AI-based career recommendations.

## Features
- Resume parsing
- Skill extraction
- Role matching
- ATS score
- AI suggestions (OpenAI)

## Tech Stack
- Python
- Streamlit
- NLP
- OpenAI API

## Run Locally
pip install -r requirements.txt
streamlit run app.py
